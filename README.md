# Personal-Productivity-Toolbox
一个提高个人工作效率聚合性应用，包含Todo List、笔记/备忘录、番茄钟等，用于个人工作和学习时进行规划和反思的一个助手，覆盖组件化、状态管理、路由、第三方库继承、数据可视化等
# 个人生产力工具箱 (Productivity Toolkit)

一个集成了待办事项、笔记、番茄钟和数据可视化的现代化Web应用，旨在帮助用户提升个人效率。

##  功能特性

 **任务管理**：创建、编辑、删除和标记待办事项，支持分类和优先级设置。
 **笔记系统**：使用富文本编辑器编写笔记，支持Markdown，可保存为本地文件或导出。
 **番茄钟**：可自定义的番茄工作法计时器，支持通知和统计。
 **数据看板**：使用ECharts可视化任务完成情况、学习时长分布等统计信息。

##  技术栈

 **前端框架**：Vue 3 + Composition API
 **状态管理**：Pinia
 **构建工具**：Vite
 **UI组件库**：Element Plus
 **图表库**：ECharts
 **富文本编辑器**：Toast UI Editor
 **图标**：Font Awesome 或 Element Plus Icons
 **样式**：Sass/SCSS（可选）

 ##  快速开始

### 环境要求
- Node.js >= 16.0
- npm >= 7.0 或 yarn >= 1.22

### 安装与运行
```bash
# 克隆项目
git clone https://github.com/wdlxr/Personal-Productivity-Toolbox.git

# 进入目录
cd productivity-toolkit

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
